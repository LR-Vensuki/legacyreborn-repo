Клиент **Яндекс Музыки** для iOS 6: лента, поиск, избранное, плейлисты и воспроизведение, в том числе в фоне.

Форк одноимённого проекта [iYMLegacy](https://github.com/igkuzm/iYMLegacy) от igkuzm (Igor V. Sementsov), доработанный LegacyReborn Project.

**Что изменено в форке**

- Вход через Яндекс OAuth по коду устройства: код копируется в буфер обмена, страницу подтверждения указывает сам Яндекс; токен обновляется автоматически.
- Новая схема получения ссылок на треки, исправлены поиск и изменение плейлистов.
- Ошибки сервера показываются в приложении, а не только в журнале.
- Часть сетевых запросов перенесена в фон, чтобы не подвешивать интерфейс; исправлены утечки памяти.

**Вход**: нажмите Connect, откройте на любом устройстве страницу Яндекса, указанную в окне, и введите код. Приложение само увидит, что вход подтверждён.

У Яндекс Музыки нет стабильного открытого API для сторонних клиентов, поэтому изменения на стороне Яндекса могут ломать отдельные функции.

Приложение также доступно в виде IPA на [странице релизов GitHub](https://github.com/LR-Vensuki/iYMLegacy/releases).
